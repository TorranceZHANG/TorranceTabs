项目工作区

保存网页、窗口与分组，之后按原结构恢复工作现场。

保存与恢复范围

恢复时会复用已经打开的网页，已有页面保持当前位置。不会保存登录状态、表单内容或滚动位置；无痕、共享组、分屏和内部页面会跳过。

撤销重复页清理

恢复原网址，并尽可能恢复原来的标签组。

恢复限制：未保存的表单、滚动位置和页面运行状态无法保证恢复；中断记录不会自动重试。记录保存在本机，最多 500 条、10 批。

备份与迁移

导出分组设置、稍后读、常用入口、去重规则和工作区。

注意：备份可能含内部链接，请妥善保管。授权和临时提醒不会导出。

支持 JSON 文件，最大 1 MB。

自动快照

保存当前全部普通窗口，内容未变化时不重复保存。共享、无痕、分屏和内部页面跳过。

历史和快照仅存本机，有总容量上限；快照保存链接和布局，无法恢复表单或页面运行状态。

按需跨机器同步

通过 Chrome 同步存储传递所选设置。需要相同扩展身份与已启用同步的 Chrome 账号；各设备分别上传，应用前先预览。

同步未启用

参与本次操作的内容

每台设备最多上传 7 KiB，最多 8 台。稍后读、工作区、历史、自动快照和临时暂停不参与同步；关闭同步会保留云端已有副本。
